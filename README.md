Harbor Yard is a round-based tactical FPS in three.js: Vanguard attackers plant a spike at the Crane or Warehouse sites while Sentinel defenders hold the container yard, with a buy phase, three invented weapons, a grenade, and bots that route, hold, and react to sight and sound.

## Run it

```sh
node serve.ts
```

then open http://localhost:8080
